# 像素粒子与书本堆叠学习界面设计

日期：2026-11-27

## 意图

把现有学习界面改成更沉浸的像素书本风格：背景由右下角向左上角形成像素粒子渐变，词汇、语句与阅读使用有景深的纸张 / 书本堆叠效果。手机可左右滑动翻页，PC 保留按钮点击翻页，同时不损害学习效率与可读性。

## 目标

- 全站采用一致的像素粒子背景、纸张卡片和清晰视觉层级。
- 复用统一的卡片堆叠与翻页组件，覆盖词汇和阅读段落；例句、对话语句采用同一书本视觉语言。
- 手机支持水平滑动翻页，保留可访问的翻页按钮；PC 支持按钮和左右方向键。
- 顶层正文始终清晰，后层卡片通过错位、缩放、色调和柔和投影形成景深。
- 尊重 `prefers-reduced-motion`，不依赖悬停，不产生横向页面滚动。

## 非目标与反目标

- 不迁移框架，不引入 Canvas 动画、3D 引擎或新依赖。
- 不修改后端 API、课程内容、学习数据库、复习排期或评分规则。
- 不用持续飘动、强烈闪烁或模糊正文制造效果，不让翻页手势破坏垂直滚动、文字选择、点词或按钮操作。
- 不把文章理解题、完成阅读或中文开关藏进手势中。

## 约束

- 沿用 `app/static/` 的原生 HTML、CSS、JavaScript 与当前启动方式。
- 保留当前工作区已有修改，只调整本任务相关前端与针对性浏览器测试。
- 桌面和手机共用同一页面，手机输入区不得被底部导航遮挡。
- 所有学习内容仍按文本安全渲染。

## 方案比较与选择

1. **纯 CSS 像素粒子与轻量 DOM 翻页（已选择）**：以多层方形背景渐变构成右下到左上的粒子密度 / 色彩变化，以伪元素构成书页后层；扩展现有 `cardDeck`。无新增依赖，性能和可维护性最好。
2. **Canvas 动态粒子与 3D 翻页**：动态感更强，但动画、触控、滚动、减少动态效果和测试成本明显增加，不符合本次克制改造。

## 已确认的实现决定

- 将用户所说“手机端可以滑动翻译”按上下文理解为“手机端可以滑动翻页”。
- 背景采用静态像素颗粒，不做持续飘动。
- 词汇按当前队列逐项翻页；阅读文章按段落翻页，理解题与“读完了”仍保留在文章之后。
- 翻页只改变当前页展示，不自动标会、不自动评分、不自动完成课程。
- 手机也保留翻页按钮作为可访问的替代操作；PC 按钮不删除。
- 景深仅用于装饰性后层与过渡，正文保持清晰。

## 留给实现者的决定

- 在不覆盖现有功能样式的前提下确定具体配色、像素尺寸、书页层数和断点。
- 阅读页码使用页面内临时状态即可，不新增服务端进度字段。
- 根据真实内容高度处理卡片内部滚动，避免小屏按钮不可达。

## 验证

- 运行现有学习 / AI 单元测试，确认无后端回归。
- 使用临时数据库进行浏览器回归，覆盖桌面与 393×852 手机视口。
- 验证词汇按钮翻页、手机水平滑动、垂直滚动、阅读逐段翻页、点词标会、理解题与完成阅读。
- 检查页面无横向溢出、控件可见可点、减少动态效果可用；只有真实设备实测才可称为真机验证。
