# 四级精读课表与「会 / 不会」间隔重现

日期：2026-11-27  
状态：待确认（未实现）

## Intent

把 self-english 的默认学习路径从入门 A1 抬到「大学英语差一点四级」。每课以一篇完整短文为主轴；文中标出词汇、语法、短句。学习者标「会」或「不会」。「会」的条目从后续课文的教学划线里拿掉，按间隔几周再漏出来复习，不是永久删除。

服务的是这一个使用者，不是四级真题机，也不再把入门第一册当作首页主线。

## Goals

- 五个页面仍是：今天、词汇、阅读、对话、进度。
- 阅读是一篇约 280–350 词的完整英文，一页可滚动，不是一句一翻。
- 划线种类仍分词汇、语法、短句；点开看音标、意思，再标会 / 不会。
- 「会」后下一篇（以及未到期的课文）不再把该条当生词展示；到期后漏出。
- 间隔按简化艾宾浩斯：会之后先隔约两周，再约一个月，再约两个月。
- 「不会」留在本课词卡和课文划线里，直到改标为会。
- 课文原创，不搬四级真题、不搬新概念。
- 不清空 `data/learning.db`。入门课退出课表，旧复习卡可继续到期，不自动删除。

## Non-goals

- 不做听力试卷、选词填空、作文批改、分数报告。
- 不按个人词表用 AI 现写每篇文章。
- 不把已会的词从英文正文里删掉。
- 不改技术栈，不把服务暴露到公网。
- 第一批不做六个月全部课表，只换掉默认主线的第一批课。

## Anti-goals

- 首页仍从「Excuse me / 点餐」入门课开始。
- 用完成率或理解题正确率冒充四级水平。
- 把系统朗读说成录音。

## Constraints

- Python / FastAPI / SQLite / `app/static/`。学习数据在 `data/learning.db`。
- 课程、词条用稳定 ID，不靠 SQLite rowid。
- 改表保留旧行；种子可重复导入。
- 词条 ID 必须跨课稳定：同一 headword 在第 1 篇和第 3 篇是同一张复习卡。
- 时间按 UTC 存储，到期日按使用者本地日期。
- 测试用临时库，不碰真实学习库。

## Approaches

考虑过三条：

1. **精读主轴（选定）**：每课一篇长文；词汇从文中来；阅读整篇；对话围绕话题；会 / 不会 + 间隔漏出。符合「阅读是长篇」和「整体抬到四级」。
2. 只把现有 17 课写长写难，仍走 Excuse me / 点餐。否决：话题仍是入门。
3. 改成四级试卷。否决：对不上现有词卡–阅读–对话，也不能用真题。

选定 1，外加会 / 不会与艾宾浩斯式漏出。

## 课表

新课用新 ID，例如 `cet4-01-drop-course`。`LESSONS` 只含新课。`ROADMAP` 第一个月改为「四级精读」。`level` 为 `CET-4`。

第一批 6 课（原创，校园 / 日常，难度接近四级仔细阅读）：

1. 这门选修该不该退（第一篇划线更密，约 24–32 条）
2. 实习申请邮件
3. 小组作业合不来
4. 兼职和课业
5. 出行延误
6. 网上这条消息靠不靠谱

之后各课新划线约 12–18 条，外加到期漏出的旧词。每课对白 8–12 句，理解题 4 道（主旨 / 细节 / 词义 / 推断，不是入门句型题）。对话任务用英文谈本课立场。

入门 `book1-*` 与场景课不再进入 `LESSONS`。旧进度行留在库里，首页不再点名去上那些课。

## 五个底栏页（独立）

底部（桌面侧栏同一套）五个标签互不绑「这一课进行到哪一步」，去掉顶部本课步骤条。

- **今天**：到期复习（含漏出的会）、下一篇推荐阅读、对话入口。文章列表全部可点，不锁关。
- **词汇**：全局队列，只出「不会」和到期漏出。词句库仍可从本页进。
- **阅读**：文章列表；点进一篇是整篇 280–350 词精读 + 理解题。这是长篇阅读。
- **对话**：话题列表，点进一题再写英文。不要求先读完对应文章。
- **进度**：复习格与文章完成情况。不写「已达四级」。

## 划线与会 / 不会

正文始终是完整英文。教学层（划线、词卡）按状态过滤。

| 状态 | 课文划线 | 词卡 | 今天复习 |
|------|----------|------|----------|
| 未标 | 显示 | 等学习者标过再进词卡；本课未标完也可先读 | 无 |
| 不会 | 显示 | 显示 | 可按短间隔到期 |
| 会且未到期 | 不显示 | 不显示 | 不到期不出现 |
| 会且到期 | 若本课正文含这条则再划出（复习漏出） | 若出现在本课则进入词卡 | 到期卡必出现，即使当前课没有这个词 |
| 漏出时改标不会 | 重新当生词 | 重新进入 | 明天再见到 |

点划线：音标、中文意思、种类（词汇 / 语法 / 短句）、会、不会。标错可再点改。会 / 不会立刻写入学习库，下一课、刷新、另一台设备以服务端为准。

未标的条目仍划线，避免第一篇「还没点过」就被藏掉。第一篇鼓励把划线点完；不强制点完才能翻到理解题（builder 可加温和提示，不阻断阅读）。

## 间隔（会 = 长间隔）

现有复习是「忘了 1 天 / 模糊 2 天 / 记得 1–3–7–14 天」。对「会」太短，不够「隔几周漏一次」。

新轨道（本设计的调用）：

- **会**：盒子 +1，等待 **14 / 30 / 60 / 60** 天（最高盒 4，满级仍 60 天）。
- **不会**：盒子回到 1，**1 天后**再作为生词出现。
- **模糊**（仅今天复习卡保留，阅读弹出可以没有）：盒不变，**2 天后**再漏。

阅读弹出只用会 / 不会。今天复习卡：会、不会，可选保留模糊，避免和旧卡两套按钮打架。旧入门复习卡仍用忘了 / 模糊 / 记得，互不改写对方间隔表。

到期日按使用者本地日期：14 天后的那天进入「今天」。

## 数据

新增跨课 `headwords`（稳定 ID，如 `hw.deadline`），字段含 english、chinese、kind（`vocab` | `grammar` | `phrase`）、音标、释义、可选语法 teach。课文 `marks` 带同一个 `headword`。复习卡主键改为 headword ID，使第 1 课标会的 `deadline` 和第 3 课是同一张卡。

种子仍可把同一 headword 写进多课划线；展示时按上表过滤。

`kind` 增加 `phrase`。语法项可继续带 `teach`（怎么问 / 怎么回 / 换词 / 为什么），短语和词汇用注释 + 例句。

改表升级：旧 `review_cards` 保留。新卡用 `hw.*`。不要把入门卡迁移成四级词。

## 阅读界面

- 一篇文章一个卡片：标题、词数、全部段落连续排列。
- 每段英文划线 + 可关中文 + 本段朗读（系统语音，标明不是录音）。
- 理解题接在文后，同一阅读步骤内，不再和「短对话」捆成最后一页。
- 对白回到对话页，不塞进阅读。
- 手机宽度（约 392）不横向滚动；底部导航不挡住最后一段和按钮。

## 诚实与来源

- 课文 `source: original`，注明原创、非真题。
- 朗读文案保持「设备系统语音，不是录音」。
- 进度页只展示课次和复习格，不写「已达四级」。

## What’s left to the builder

- 六篇正文的具体用词和情节，只要篇幅、难度、划线密度符合上文。
- 漏出划线的视觉差异（与生词区分但不靠悬停）。
- 阅读未标完时的提示文案。
- 语法 teach 写哪些四级句型。
- 测试如何造「14 天后到期」：改时钟或注入 `due_at`。
- CSS / 缓存 `?v=` 递增。

## 验证（实现时）

- headword 标会后，下一课 payload 的 marks / 词卡不含该条；改 `due_at` 为过去后重新包含。
- 不会 → 会 → 不会 来回改，划线和词卡跟着变。
- 旧学习库升级不丢复习卡；首页当前课是 `cet4-01-*`。
- 每篇英文词数 ≥ 280；第一课划线 ≥ 24。
- 相关 unittest；阅读页桌面与手机宽度看一遍。
