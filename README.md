# self-english

一人用的英语学习应用。电脑跑服务，手机和平板用浏览器打开同一套页面。默认课表是六篇原创精读，难度接近大学英语四级仔细阅读，不是真题，也不是新概念课文。

五个页面互相独立：今天、词汇、阅读、对话、进度。桌面左侧导航，手机底部导航。阅读是长篇文章库，不是某一课的中间步骤。进度页用图表看半年路线、本月课程、复习格子和评分，时间按本地日期显示。

## 启动

词库不是课程的前置条件。没有 `data/app.db` 时，首页和已有课程仍可学；词句库会提示如何构建。

```powershell
git clone https://github.com/wuhanwoaini521/self-english.git
cd self-english
uv sync
uv run uvicorn app.main:app --host 0.0.0.0 --port 8000
```

这台电脑打开 http://127.0.0.1:8000 。同一局域网的手机用这台电脑的地址，端口 8000。若手机打不开，在 Windows 防火墙里允许 Python 访问专用网络。

可选：把 `.env.example` 复制为 `.env`，填入 DeepSeek 密钥后重启服务。对话页会把**这一课的任务说明、目标列表和你刚写的英文**发给 DeepSeek，用来判断是否说到目标，并回一句对方的话。不传录音，不传复习卡，不把密钥或完整对话写入普通日志。没配密钥时仍用关键词脚本，不访问外网。DeepSeek 按 token 计费，一回合大约几十到几百 token，默认关闭。实时语音 API 只留了接口和按钮，现在不会发送麦克风数据。

可选：下载公开词表并生成词句库（不影响学习进度）。家里电脑会收录 CEFR-J 的 A1–B1 词，以及最多约 4000 条短句：

```powershell
uv run python scripts\download_sources.py
uv run python scripts\build_catalog.py
```

## 数据

- `data/app.db`：可重建的词句目录。重建脚本先生成并校验临时库，成功后再替换它。
- `data/learning.db`：课程进度、复习卡、对话记录。不进 git。重建词库不会改这份文件。
- `data/raw/`：下载的词典和句对，不进 git。

来源和许可见 `data/SOURCES.txt`。课程课文均为原创，不能收录《新概念英语》原文。点朗读用的是这台设备自带的语音，不是真人录音。手机没声音时先开媒体音量；若仍无声，在系统设置的文字转语音里下载英语语音包。

## 怎么学

首页给出下一篇建议，并列出全部文章；点开即可读，不必按课内步骤走。阅读页是完整短文：浅蓝虚线是词汇，紫色实线是语法，点线下划线是短句。生词默认都算不会，点开标「会」即可。标会的词下一篇不再划出，按 14 / 30 / 60 天再漏出来。标错过会，可在到期漏出时改回「还不会」。文章下面有理解题，读完可点「读完了」。

词汇页列出还不会的词和到期漏出的词，也可以进词句库。对话页单独选话题写英文。没有每天上限。已读完的文章可以再打开。点朗读用的是这台设备自带的语音，不是真人录音。

首页到期复习仍是先看英文、翻开后再选忘了 / 模糊 / 记得（盒子回到 1 隔 1 天、不变隔 2 天、加 1 后隔 3 / 7 / 14 天）。同一表达重复加入只会有一张卡。

启动时会自动给旧版学习库补充进度版本和评分操作标识。已完成课程可回看重答；两台设备同时保存时，页面会提示冲突并同步位置。网络中断后在当前页重试评分，服务端只记一次。
